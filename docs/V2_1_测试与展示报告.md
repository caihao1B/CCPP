# CCPP 2.1.0 与个人网站重设计：测试、实验与能力边界

本轮基线是 CCPP_Mowing_Planner_v2.0.1_Audited；不是仅修改网页曲线显示。日期2026-10-22。代码改动、全部十组新结果和网站素材都在本轮生成。网站尚未上传GitHub。

## 一、本轮实际改动

展示主线统一为“田块和任务网格 → 覆盖任务访问顺序 → 安全连接折线 → 受运动约束的曲线 → 时间参数化与回放”。A*保留为连接工具，不再作为独立项目拆开讲述。

旧版差速模式在局部平滑失败后可能合法地采用有限角速度的原地TURN；旧动画高倍速或视频重置也可能造成瞬间改向的观感。不能仅凭观感断言原程序数学上瞬时修改了航向。本轮新增明确策略：

- `legacy_pivot`：保留旧行为，兼容旧配置与旧结果。
- `loop_then_pivot`：先尝试无碰撞的向前回环，失败且允许时才记录原地回退。
- `loops_only`：必须找到满足约束的移动曲线，失败则拒绝；不得偷偷原地转向、缩小半径或改变任务顺序。

网页的十组新案例全采用loops_only。对反向访问，通过Dubins候选构造同点改向或跨行连接。具体形状由起终位置与航向决定，不强制字面“8”字；没有实现Reeds–Shepp倒车规划。

对SLSQP优化候选，若独立连续证书不通过，先尝试同裁切距离的固定G2 Bézier形状，再考虑更长回环；这项回退被计数，不作为“全部数值优化成功”汇报。优化成功标志不能替代安全校验。

新增curve段组turn_id，使GUI、网页与视频可以播放整个回环，而不只截取一个圆弧。网页到局部片段末端停止，不自动重置姿态。GUI新增Turn treatment、研究车辆JSON选择和Heading loop按钮。推荐预设08—12；01—07保留并标注legacy baseline。

## 五、运动与安全约束

各条曲线都保留解析几何和同一时间参数模型；航向来自曲线切线。独立复验检查工具服务、完整矩形车体的保守扫掠包络、曲率/最小半径、线速度、纵向加速度/jerk、航向角速度/加速度/jerk、横向加速度，前进模型另检查等效转舵速率。角度跨±π时以连续航向解释，不能按数值符号跳变误判车体瞬时旋转。

所有展示案例前进速度非负；补充检查中等效左右轮/履带速度也没有负值。正反向回访不等于倒车：机器人可以绕行改变航向，再向相反的世界坐标方向前进。

Bézier与直线可具有G2几何接续；Dubins包含定曲率圆弧与直线，曲率不必连续。本实现因此在基本段交界停止，前进模型有限速转舵后再走。**不能宣称全路径G2、全程非零速度或任意车辆动态可执行。** 时间参数已约束运动导数，但没有质量、轮胎力、打滑、接地、执行器力矩或能耗辨识，也没有定位反馈跟踪控制器。

六类Dubins候选加若干半径尝试是局部候选生成，不是有障碍SE(2)空间中的完备搜索；局部失败不证明物理空间绝对无路。loops_only坚持失败可见，不以原地回退伪造成功。
